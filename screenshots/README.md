# Evidence images

Provided images in this folder are actual local browser captures, when available.
Graphs in reports/figures are computed plots, not deployment screenshots.

Capture these on your own machine after following README:

1. `github-actions.png` - successful workflow with lint, training, tests, Docker smoke.
2. `docker-proof.png` - build completion, smoke PASS and healthy container status.
3. `kubernetes.png` - rollout success, two ready pods and Ingress resource.
4. `ingress-prediction.png` - real /predict response through ingress.
5. `grafana.png` - provisioned dashboard after generating traffic.
6. `prometheus.png` - target UP and request metric query.

Do not substitute sample images or this guide for execution evidence. Add the
images to the report's corresponding evidence sections and preserve ten pages.
